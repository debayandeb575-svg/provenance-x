Advanced FastAPI backend for the Provenance-X evidence integrity platform.

- Evidence upload
- SHA-256 evidence hashing

- Provenance event chain
- Merkle-tree integrity
- Merkle inclusion proofs
- Ed25519 signatures
- Witness attestations
- Evidence verification
- Evidence download
- JSON verification reports
- React/Vite CORS support
- OpenAPI documentation
